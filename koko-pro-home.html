How it works

From registry to production in three steps.

No wrappers, no runtime. Just the source code dropped into your repo, ready to edit.

  1. 01

    Install

    One command with shadcn/cli pulls a component into your project with all dependencies wired up

    bunx shadcn@latest add @kokonutui/hero
  2. 02

    Compose

    Tweak TailwindCSS, compose with the rest of your design system. No lock-in, no abstraction

    <Hero title="Your product" />
  3. 03

    Ship

    Deploy to Vercel, Netlify, or anywhere Next.js runs. Entire landing pages in an instant

    git push, live
