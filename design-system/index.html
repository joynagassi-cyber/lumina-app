⚖️ Principes Fondamentaux
INV-001
Transaction Immutable
Une transaction validée ne peut plus être modifiée. C'est la règle absolue de confiance financière.
INV-002
Platform Core Universel
Le cœur de Lumina ne connaît aucune logique métier spécifique. Seules les organisations abstraites.
INV-003
Toujours Hors-Ligne
L'application doit fonctionner à 100% offline avec synchronisation automatique.
NB-04
Header x-org-id Obligatoire
Chaque appel API doit inclure l'en-tête d'identification multi-tenant.
NB-07
Zéro Type `any`
Le TypeScript doit être strictement typé — aucun type `any` n'est permis.
Finance First
Priorité Absolue
Le module financier est la priorité numéros 1. Coverage tests >= 90% requis.
